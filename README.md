# 🏠 Property Management

A web application for **property management**, built with React and TypeScript on the frontend and Node.js, Express, and TypeScript on the backend.

## 🛠️ Technologies

### Frontend

* React 19
* TypeScript
* Vite
* Redux Toolkit
* React Router
* Axios
* Bootstrap
* React Leaflet / Leaflet
* SweetAlert2

### Backend

* Node.js
* TypeScript
* Express
* MongoDB / Mongoose
* MySQL / Sequelize
* JWT
* bcrypt
* PDFKit

## ✨ Features

* Property management
* User authentication
* Data management
* Interactive maps
* PDF generation
* Form validation
* Notifications and alerts

## 🚀 Installation

### Backend

```bash
cd backET
npm install
npm run server
```

### Frontend

```bash
cd frontRT
npm install
npm run dev
```

## 📦 Production

### Backend

```bash
npm run build
npm start
```

### Frontend

```bash
npm run build
npm run preview
```
